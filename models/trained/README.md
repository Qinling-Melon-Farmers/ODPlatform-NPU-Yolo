# 训练产出模型目录

| 属性 | 值 |
|------|-----|
| **状态** | Active |
| **所属** | ODPlatform 顶层共享资产（产物） |

---

## 用途

存放**你训练产出、决定长期保留**的模型权重文件（如 `best.pt`、`last.pt`）。

这些是"产物"——从训练流程生成、可被删除后重新训练再生。

---

## 与 runs/ 的分工

| 目录 | 存放内容 |
|------|---------|
| `runs/` | **每一次**训练的全部痕迹（日志、曲线、检查点），数量越来越多 |
| `models/trained/` | 从 runs/ 中**挑选出来、要长期使用**的几个权重 |

---

## 不进 Git

所有 `.pt` 文件被 `.gitignore` 排除，不会进入版本库。
