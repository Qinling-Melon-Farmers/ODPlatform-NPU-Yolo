# 预训练模型目录

| 属性 | 值 |
|------|-----|
| **状态** | Active |
| **所属** | ODPlatform 顶层共享资产（输入） |

---

## 用途

存放**从外部下载**的预训练权重文件（如 `yolo11n.pt`、`yolo11s.pt` 等）。

这些是"输入"——你从外部获取、只读使用、不在此修改。

---

## 放入方式

从 Ultralytics 官方或其他来源下载 `.pt` 文件后放入此目录，例如：

```bash
# YOLO 首次运行时会自动下载到这里
# 也可以手动下载后放入
```

---

## 不进 Git

所有 `.pt` 权重文件被 `.gitignore` 排除，不会进入版本库。
