## 本阶段明确不做

| 项目 | 决策 |
| --- | --- |
| Web 端 | 暂不推进，不创建新的 Web 前后端实现。 |
| exe 打包 | 用户已明确先不考虑打包。 |
| `segment` 端到端 | 当前项目定位为 steel defect `detect`；`segment` 标为未来扩展。 |
| 深度相机 / 红外相机 | 需要硬件和驱动支持，暂不纳入。 |
| Word 报告 | 已有 JSON / Markdown / HTML / CSV/Excel，Word 暂列未来扩展。 |

## 后续可选增强

1. 桌面端本地运行产物安全删除入口，复用 `odp-reset` 的 dry-run、保护目录和备份逻辑。
2. 桌面端任务模板保存、运行历史复用和多 run 训练曲线对比。
3. 数据质检增加重复图像 hash 检查、超大/超小框检查、空标签白名单。
4. 推理 frame source 注册表化，为 RTSP、深度相机、红外相机接入做准备。
5. 对摄像头、RTSP/HTTP 流、OpenCV 窗口暂停等真实环境分支增加人工 smoke 记录或更轻量自动化。
6. 独立做一次中文编码清理，避免早期文件注释和日志文案在不同终端显示乱码。
