# 架构决策记录（ADR）

本目录存放 ODPlatform 项目的**架构决策记录**（Architecture Decision Records）。

---

## 什么是 ADR

ADR 是一份简短的文档，记录一次重要的架构决策，包括：

- 当时面临什么问题
- 有哪些可选方案
- 为什么选了当前方案
- 这个选择带来的后果（好的和坏的）
- 什么条件下应该重新评估这个决定

它的核心价值是：**为半年后的接手者保留"当初为什么这么做"的化石记录。**

## 如何新增 ADR

1. 在本目录创建 `ADR-<编号>-<简短描述>.md`
2. 参考 [ADR-001](ADR-001-monorepo.md) 的章节结构
3. 提交 PR 经架构组评审后合入
