# 训练运行产物目录

| 属性 | 值 |
|------|-----|
| **状态** | Active |
| **所属** | ODPlatform 顶层共享资产（过程现场） |

---

## 用途

存放**每一次训练运行**的完整现场记录：

- 训练日志（loss 曲线、mAP 变化）
- 中间检查点（checkpoint）
- 配置文件快照
- 评估指标报告

---

## 使用规范

1. 每次训练自动在此创建新子目录（按时间戳或实验名区分）
2. 从 `runs/` 中挑选效果最好的权重，**复制**到 `models/trained/` 长期保存
3. `runs/` 中的内容可以定期清理（失了可以从代码 + 数据重新生成）

---

## 不进 Git

`runs/` 下所有内容被 `.gitignore` 排除，仅此 README 进入版本库。
